# アプリケーション基本仕様

## 1. 目的

コンソール版および GUI 版として利用できる、簡易ウェブサーバーを作成する。

## 2. 共通要件

- サーバーはアプリケーションの実行中に限り動作する。
- サーバーは HTTP と HTTPS の両方で待ち受ける。
- 既定ポートはCLI版・GUI版ともに HTTP が 80、HTTPS が 443。
- HTTP/1.1 プロトコルでリクエストを受け付け、HTML その他のコンテンツを応答する。
- アプリケーションの終了に伴い、サーバーの待ち受けも終了する。

## 3. アプリケーションの種類

本プロジェクトでは、次の 2 種類を、共通の Visual Studio 2026 用ソリューション `LocalHttpDaemon.slnx` に含める。実行ファイルとプロジェクトは独立させる。

| 種類 | ソリューション | プロジェクト |
| --- | --- | --- |
| コンソール版 | `LocalHttpDaemon.slnx` | `CLI_LocalHttpDaemon/` |
| GUI 版 | `LocalHttpDaemon.slnx` | `GUI_LocalHttpDaemon/` |

## 4. 現在のプロジェクト設定

- コンソール版は .NET 10 (`net10.0`) を対象とする。
- GUI 版は WPF を使用し、Windows 向け .NET 10 (`net10.0-windows`) を対象とする。

## 5. コンソール版の仕様

- `CLI_LocalHttpDaemon` はコンソールから起動・利用する。
- 設定ファイルがない場合の既定ポートは HTTP 80、HTTPS 443。`--root` も保存済みルートもない場合は、指定を促す案内とコマンドラインオプションのヘルプを表示し、待ち受けず正常終了する。
- `--root <絶対パス>` で配信する HTML 等のルートフォルダを指定する。
- `--root` のフォルダ区切りには `\` と `/` のどちらも使用できる。
- `--port <httpポート>[/<httpsポート>]` でポートを指定する（例: `--port 80/443`）。`--port 80` または `--port 80/` は HTTP のみ更新し、HTTPS は保存済み値または既定値を維持する。両ポートには 1〜65535 の異なる番号を指定する。
- EXEと同じフォルダの `settings.json` を起動時に読み込み、コマンドラインの `--root`・`--port` を優先する。起動可能な設定は同じ場所に保存する。GUI版と同じ設定クラスを使用し、設定ファイルを相互利用できる。
- `https://localhost/index.html` のリクエストは、指定ルートフォルダ直下の `index.html` を返す。ルート URL `/` は `index.html` として扱う。
- HTTP/1.1 で GET および HEAD を受け付け、ファイルの種類に応じた Content-Type で応答する。ディレクトリ外へのパストラバーサルを拒否し、存在しないファイルには 404 を返す。
- すべてのアクセスと処理エラーをGUI版と同じ形式・色でコンソールに表示する。POST の処理自体は未対応メソッドとして扱う。詳細は `CLI版アプリケーション仕様.md` を参照する。
- HTTPS 用証明書は初回起動時に localhost 用の自己署名証明書を作成し、ユーザーの Local Application Data 内に保存して再利用する。ブラウザで信頼警告が出る場合がある。
- 受信接続は localhost (loopback) に限定する。ポート 80 のバインドには環境によって管理者権限が必要となる。
- HTTPS の既定待ち受けポートは 443。既定設定では `https://localhost/index.html` でアクセスできる。保存済みのポート番号は既定値の変更で上書きしない。
- 起動成功時は配信ルートを `ROOT : <絶対パス>` と表示し、HTTPとHTTPSのURLを表示する。
- Ctrl+C で終了し、プロセス終了時に待ち受けを停止する。
- CLI は .NET ランタイム未導入の Windows x64 環境でも実行できる、自己完結型の単一ファイル発行に対応する。Release ビルド・再ビルド時に単独 EXE と README を含む ZIP を自動生成する。出力先は `CLI_LocalHttpDaemon_Package/`。詳細は `ソリューション構成・ビルド仕様.md` を参照する。
